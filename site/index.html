02 / REPOSITORIES

One family. Five repositories.

Two Python libraries provide the device interfaces. Two hand-maintained HACS integrations bring them into Home Assistant, importing the libraries from PyPI. A dormant umbrella overlay is kept for a possible Home Assistant core contribution.

HACS allows one integration (one domain) per repository, so each device gets its own hand-maintained HACS repository. These repositories own their integration code and tests. The dormant umbrella ha-mygrid-core keeps a single mygrid domain and is shaped for a possible Home Assistant core contribution. A core contribution is not guaranteed. The HACS entries do not migrate to the core entry because they use different domains.

Which repository to use

ha-mygrid-voltbridgeInstall or contribute to the VoltBridge HACS integration (domain mygrid_voltbridge), using the library from PyPI.
